# Lyria Telegram Bot

Приватный Telegram-бот для генерации песен из текста с использованием OpenRouter (модель Lyria).

## Описание

Бот позволяет авторизованным пользователям отправлять стихотворный текст и получать в ответ сгенерированную песню в формате MP3.

## Структура проекта

- `config.py` — загрузка переменных окружения и настроек.
- `models.py` — SQLAlchemy модели (User).
- `database.py` — настройка асинхронного движка БД и сессий.
- `services/generation.py` — логика генерации аудио через OpenRouter или мок-файл.
- `middlewares/auth.py` — middleware для авторизации пользователей по ключу доступа.
- `handlers.py` — обработчики команд и сообщений.
- `bot.py` — точка входа, инициализация и запуск бота.
