1. Добавить services/enricher.py
	ФункциИ внутри - 
		enrich_prompt(prompt: str) -> str | None: ... # обогащает промпт
		save_enriched_prompt(prompt: str) -> None: ... # Сохраняет обогащенный промпт (приходит от хэндлера) в БД
2. Сформировать запрос для API (системный промпт живет в настройках модели в Open WebUI, пользовательский приходит снаружи)
	ENRICH_URL
	ENRICH_TOKEN
	ENRICH_MODEL 
	хранятся в переменных окружения.
	Читаются через config.py (класс EnrichPromptConfig(BaseModelConfig)) и импортируются из этого модуля через инстанс settings
3. HTTP-запрос по к нужной модели
4. Парсинг результата, возврат строки с ним

Сервис ничего не должен знать о телеграмме. По сути, это http-клиент с парсером JSON-ответа. Сложную структуру нет необходимости обходить рекурсивно - API OpenAI имеет четкие контракты
