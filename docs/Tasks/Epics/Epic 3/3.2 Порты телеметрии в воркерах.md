### Реализовано:
1. **Абстрактный порт** (`src/shared/ports/telegram.py`):

3. **Тесты** (`tests/unit/test_telegram_port.py`):

   - Проверка автоинкремента ID

### Использование:
```python
# В воркерах
port = AiogramTelegramPort(bot_token=settings.bot.token, owner_id=settings.bot.owner_id)
await port.send_message(chat_id=user_id, text="Генерация завершена")
await port.send_audio(chat_id=user_id, audio=audio_bytes, title="Моя песня")

# В тестах
port = FakeTelegramPort()
await port.send_message(chat_id=123, text="Test")
```
