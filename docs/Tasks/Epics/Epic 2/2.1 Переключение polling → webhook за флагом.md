- Описание: FastAPI-приложение с эндпоинтом вебхука, aiogram `Dispatcher` в режиме webhook через `Bot.set_webhook` (`secret_token` обязателен, `drop_pending_updates=True` при старте). Флаг `WEBHOOK_MODE` в конфиге: локально остаётся polling bot.py — на Ubuntu без белого IP webhook не заведёшь без плясок с ngrok.
- DoD: оба режима работают, переключаются env'ом; CI-пайплайн гоняет тесты в обоих режимах инициализации диспетчера.
- Edge case, который надо закрыть: deduplication по `update_id` — Telegram может ретраить вебхук при таймауте ответа; отвечать `200` сразу, обработку запускать в фоне.
