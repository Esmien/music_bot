Реестры живут в трёх разных местах 
`pending_auth` — в Redis, переживает рестарт. 
`active_tasks` — «память процесса», uid процесса можно хранить в Redis
`failed_key_attempts` — тоже память, с честным комментарием «сбрасывается при перезапуске» auth.py. 
Для бота с одним пользователем — простительно. 
Но это архитектурная заноза: после рестарта бот забывает, кто перебирал ключи, и теряет активные генерации.
Унифицировать - единая точка реестров - Redis
