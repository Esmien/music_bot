Флоу:
1. Юзер в стейте `waiting_for_idea` присылает текст.
    
2. Бот делает `await state.update_data(prompt=text)`, отправляет текст в Enricher (Open WebUI) и показывает лоадер.
    
3. Приходит обогащенный промпт -> `await state.update_data(enriched_prompt=result)`.
    
4.  Бот выдает текст с инлайн-кнопками (Одобрить / Изменить) и ставит стейт `waiting_for_approval`.
    
5. Если нажато «Изменить» -> переводим в `waiting_for_edits`, ждем текст с правками, заново стучимся в Enricher с учетом хистори, возвращаемся на шаг 3.
    
6. Если «Одобрить» -> стейт `waiting_for_title`, ждем название -> финализируем, пишем всю собранную связку в БД и кидаем в генератор аудио.
