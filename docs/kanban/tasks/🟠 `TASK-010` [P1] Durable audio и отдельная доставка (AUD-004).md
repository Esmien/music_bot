- [ ] **Приоритет:** P1 (HIGH)
	**Метки:** `data-loss`, `money-loss`, `reliability`
	**Проблема:** AUD-004. Сгенерированное аудио существует только в памяти воркера до отправки в Telegram. Сбой сети при вызове Telegram приводит к потере трека, за который уже списаны деньги.
	**Решение:**
	  1. Сохранять полученный аудио-артефакт во внешнее хранилище / локальный том до отправки в Telegram.
	  2. Фиксировать путь к файлу, размер и контрольную сумму в БД.
	  3. Сделать отправку в Telegram идемпотентным отдельным шагом, использующим сохраненный файл.
	**DoD:**
	  - [ ] Аудиофайл гарантированно сохраняется на диск/storage до вызова отправки в Telegram.
	  - [ ] При ошибке Telegram повторная отправка берет готовый файл без нового обращения к генерации.
	  - [ ] Статус генерации отражает успешность создания артефакта независимо от сетевых проблем Telegram.
	  - [ ] Ruff, Mypy, Pytest проходят без ошибок.
