	**Метки:** `bug`, `reliability`
	**Проблема:** AUD-006. В режиме polling бот запускается с `handle_signals=False`, а `shutdown_event` не прерывает работу `dp.start_polling()`, из-за чего процесс не реагирует на SIGTERM корректно.
	**Решение:**
	  1. Обеспечить корректную интеграцию `shutdown_event` с циклом опроса Telegram (вызов `dp.stop_polling()` при остановке).
	  2. Гарантировать корректное завершение фоновых сессий бота и Dispatcher по сигналам SIGTERM/SIGINT.
	  3. Предусмотреть очистку ресурсов при частичном старте приложения.

	  - [x] Задан корректный таймаут ожидания завершения (`stop_grace_period`).
