- [ ] **Приоритет:** P1 (HIGH)
	**Метки:** `bug`, `reliability`
	**Проблема:** AUD-009. Освобождение блокировки генерации пользователя в `generation/service.py` выполняется через раздельные команды `GET` и `DELETE`, что создает race condition (TOCTOU) при истечении TTL.
	**Решение:**
	  1. Реализовать снятие блокировки через атомарный Lua-скрипт (compare-and-delete по значению токена).
	  2. Задать ограниченное ожидание захвата блокировки с таймаутом (bounded wait).
	**DoD:**
	  - [ ] Освобождение Redis-лока выполняется строго через Lua-скрипт с проверкой токена владельца.
	  - [ ] Чужой или протухший лок не может быть удален другим процессом.
	  - [ ] Добавлены тесты для Lua-скрипта на fakeredis или изолированном Redis.
	  - [ ] Ruff, Mypy, Pytest проходят без ошибок.
