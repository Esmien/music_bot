- [ ] **Приоритет:** P1 (HIGH)
	**Метки:** `bug`, `data-loss`, `reliability`
	**Проблема:** AUD-010. Проверка кумулятивности чанков через `startswith` ошибочно отбрасывает дельты, совпадающие с префиксом предыдущей дельты.
	**Решение:**
	  1. Реализовать сборку аудио на основе явного формата потока (чистые дельты либо явные кумулятивные кадры с отслеживанием индекса).
	  2. Добавить проверку терминального события потока (stream end).
	  3. Ввести ограничение максимального размера строки до JSON-парсинга.
	**DoD:**
	  - [ ] Повторяющиеся одинаковые дельты корректно добавляются в итоговый аудиопоток.
	  - [ ] Обрыв стрима до терминального события распознается как ошибка.
	  - [ ] Написаны unit-тесты для краевых случаев SSE-парсинга.
	  - [ ] Ruff, Mypy, Pytest проходят без ошибок.
