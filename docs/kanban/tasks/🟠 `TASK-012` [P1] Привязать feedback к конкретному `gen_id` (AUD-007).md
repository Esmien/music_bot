- [x] **Приоритет:** P1 (HIGH)
	**Метки:** `bug`, `data-loss`
	**Проблема:** AUD-007. Сервис `save_feedback` ищет последнюю успешную генерацию по `user_id`, что приводит к перезаписи или смещению оценок при отложенных кликах по старым inline-кнопкам. Ошибки БД silently проглатываются.
	**Решение:**
	  1. Передавать и валидировать конкретный `gen_id` в FSM и callback_data оценки и фидбека.
	  2. Добавить проверку принадлежности генерации текущему пользователю.
	  3. Заменить проглатывание `SQLAlchemyError` на явное логирование и возбуждение доменного исключения.
	**DoD:**
	  - [x] Сохранение оценки и отзыва выполняется строго по переданному `gen_id`.
	  - [x] Исключена привязка отзыва к чужой или случайной последней генерации.
	  - [x] Ошибки записи в БД логируются и не маскируются под успешное сохранение.
	  - [x] Ruff, Mypy, Pytest проходят без ошибок.
