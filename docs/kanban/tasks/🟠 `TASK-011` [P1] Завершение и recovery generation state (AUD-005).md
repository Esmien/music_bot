	**Метки:** `bug`, `reliability`
	**Проблема:** AUD-005. При непредвиденных ошибках в `domains/generation/worker.py` запись генерации навсегда остается в статусе `PENDING`, а пользователь блокируется от запуска новых треков.
	**Решение:**
	  1. Обернуть цикл генерации в гарантированный блок обработки исключений с установкой статуса `FAILED`.
	  2. Обновлять статус генерации с учетом `attempt_id`, чтобы устаревший воркер не перезаписывал состояние.
	  3. Сбрасывать флаг генерации в FSM при возникновении фатальных ошибок.
	**DoD:**
	  - [ ] Любое необработанное исключение переводит запись генерации в статус `FAILED`.
	  - [ ] Ошибка отправки уведомления не мешает переводу статуса в БД.
	  - [ ] Флаг `generating` в FSM корректно сбрасывается при ошибках.
	  - [ ] Написаны тесты на сбои на различных этапах пайплайна.
	  - [ ] Ruff, Mypy, Pytest проходят без ошибок.
